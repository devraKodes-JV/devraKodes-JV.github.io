Kraal

A native compiled language for safe concurrent programming, featuring ownership-based type safety, static deadlock analysis and WASM-first compilation.

Rust WASM Concurrency Ownership Systems

Project Overview

What is Kraal?

A compiled systems language designed for safe concurrent programming. The ownership-based type system catches use-after-move and double-spawn errors at compile time, while static deadlock analysis flags task conflicts before the program runs.

Key Features

  • Ownership-based type system with compile-time channel safety
  • Static deadlock analysis for concurrent tasks
  • WASM-first compilation with zero external toolchain dependencies
  • C/Go-inspired syntax with word operators and explicit control flow

Tech Stack

  • Rust - Compiler implementation
  • WASM - Primary compilation target
  • Wasmtime - Embedded runtime (no system install required)
  • Hand-written codegen - No LLVM or Emscripten dependency

Project Status

Currently at v0.3.0-alpha.1. The language syntax and ownership model are stable. The async runtime roadmap continues toward M5 with stackless coroutines in a single WASM instance.

Language Highlights

01

Ownership Safety

Channels cannot be cloned. The compiler catches use-after-move and double-spawn errors before runtime.

02

Static Deadlock Analysis

Two tasks holding one resource and waiting for each other are flagged statically, preventing deadlocks before they happen.

03

WASM-First

The entire compiler has zero dependencies on LLVM, Emscripten, or any system toolchain. It emits a hand-written .wasm module.

04

C/Go-Inspired Syntax

Type-first declarations, word operators (AND/OR/NOT), and parens-mandatory if/while for clear, unambiguous code.

Example Code

task worker(ch: Chan) {
    ch.send(42);
    ch.close();
}

fn main() {
    Chan ch = chan(1);
    ::worker(ch);          // `ch` is moved into the task
    print("ok");
}
