Project Overview

What is routinEXE?

A JavaFX desktop application for managing exercise routines, training sessions, exercise categories, and users. Works completely offline with a local SQLite database, requiring no cloud dependencies or internet connection.

Key Features

  • Users: Create, edit, and delete users (username required, age/height/weight optional)
  • Categories: Manage exercise categories (e.g., Cardio, Strength, Flexibility)
  • Exercises: CRUD for exercises assigned to categories, with description and time-based flag
  • Routines: Create routines per user with days of the week, start/end dates, and assigned exercises (sets, reps)
  • Sessions: Record training sessions by date, with exercise tracking (done/undo) and day completion status
  • Dashboard: Overview per user with statistics and navigation to all sections
  • Calendar: Calendar view for managing sessions by day and month

Tech Stack

  • Java 25 - Latest LTS with modern language features
  • JavaFX 25.0.4 - UI framework for cross-platform desktop applications
  • SQLite JDBC 3.49.1.0 - Local database connectivity
  • Gradle + Maven - Dual build system support

Project Status

Stable and production-ready. Core domain and persistence layers are mature. Database auto-seeding available with 150 exercises across 6 categories.

How to Run

Prerequisites

  • JDK 25 or higher
  • Linux (desktop app); also supports Windows and macOS (profiles in pom.xml)

Building

With Gradle

./gradlew build

With Maven

mvn clean package

Running

  • AppImage (recommended for Linux): ./dist/RoutinEXE-x86_64.AppImage
  • JAR: java -jar dist/routin-exe.jar
  • From IDE: Run the com.routineexe.view.Main class
