Open Source Project

Vantage

An offline-first business management toolkit built with modern software engineering practices, strict hexagonal architecture and pure POJO approach.

Java 25 Javalin 7 Pebble Hibernate POJO Modular Monolith Hexagonal

Project Overview

Architecture

Modular monolith where each module strictly follows hexagonal architecture (ports and adapters). This ensures framework independence, extreme testability and easy maintainability.

Tech Stack

  • Java 25 - Latest LTS with modern language features
  • Javalin 7 - Lightweight web framework
  • Pebble - Template engine for views
  • Hibernate - ORM for data persistence
  • Modular System - Java Platform Module System

Design Principles

  • Pure POJO domain model
  • No framework leakage into core business logic
  • Dependency inversion at module boundaries
  • Clear separation between domain, application and infrastructure
  • Test-first approach with high unit test coverage

Module Structure

Each module is self-contained with its own hexagonal layers. Modules communicate through well-defined interfaces, allowing independent development, testing and future extraction into microservices if needed.

Key Features

01

Hexagonal per Module

Every module has its own ports and adapters, keeping the domain pure and independent.

02

Pure POJO Domain

Business entities are plain Java objects without any framework annotations or dependencies.

03

Modular Monolith

Single deployable artifact with clear module boundaries for simplicity and performance.

04

Extreme Testability

Architecture designed for easy unit and integration testing without mocks or complex setups.
